# TRACE Stage 1 | Four-quantitative-paper expansion | November 1, 2026

The project targets *quantitative* management research: theoretical claim → cited literature; empirical claim → reported results; source location; conservative citation-existence lookups. Review remains holistic and human-led.

## Included files

- `trace_poc.py` — executable, deterministic local PDF/DOCX candidate-claim extractor. NO LLM, no network, no automatic claim–evidence alignment, no citation verification, not validated.
- `automated_run_outputs/` — **genuine output from that exact script** for four uploaded published PDFs. These outputs are demonstrably incomplete and sometimes misclassify material. The corresponding published PDFs are **not** bundled; obtain them lawfully from publishers if rerunning.
- `human_curated_claim_map.json` and `TRACE_MultiPaper_Illustrative_Evidence_Map.html` — **manually selected and checked examples**, not generated by script. Showing a future interface target, not a model evaluation.
- `TRACE_JOM_Pilot_Report.html` — earlier illustrative qualitative manuscript case, outside quantitative target scope.
- `example_quantitative.docx`, `example_result.*` — synthetic executable CLI smoke test.

## Reproducible invocation

```bash
pip install pymupdf python-docx
python trace_poc.py /path/to/authorized/manuscript.pdf --out trace_result
```

PDF-page numbers are numbered from first page of files. Journal page numbers are additionally supplied for relevant cases. Do not infer that a source in a manuscript is valid or adequate because a pointer was found.

## Observed run counts (raw, not precision/recall)

| Case | Candidate sentences | Heuristic theoretical | Heuristic empirical | Sentences with explicit table/figure pointers |
|---|---:|---:|---:|---:|
| JBV | 6 | 2 | 4 | 1 |
| JAP | 55 | 16 | 39 | 2 |
| PP | 19 | 10 | 9 | 0 |
| SMJ | 34 | 12 | 22 | 0 |

No expert gold-standard annotation of exhaustiveness was completed; these numbers are **output counts, not accuracy metrics**. Failures observed: PDF reading order/line breaks, abstract duplication, acknowledgments misclassified as claims, mixed/negative hypotheses underrepresented, inability to link tables unless explicitly named in a single sentence. A future system must fix those limitations before interpreting outputs as evidence maps.

## Four manual bibliographic checks

- Burt (2004) in JBV: https://doi.org/10.1086/421787 (University of Chicago Press)
- Locke & Latham (2002) in JAP: https://doi.org/10.1037/0003-066X.57.9.705 (APA/PubMed)
- Nyberg & Ployhart (2013) in Personnel Psychology: https://doi.org/10.5465/amr.2011.0201 (Academy of Management)
- Zollo (2009) in SMJ: https://doi.org/10.1287/orsc.1090.0459 (INFORMS)

All four checks are **researcher-conducted bibliographic existence matches**, not script outputs or full-text support tests. Only four selected cited works were checked, not the entire reference lists.

## Privacy and rights

No journal articles are redistributed in this ZIP. The local CLI sends no data to servers. A future PythonAnywhere-hosted application would receive transmitted uploads, and must disclose server-side processing, retention and any third-party calls, with clear authorization requirements. Source material licensing may restrict republication or modification; this package uses only short descriptions and references.
